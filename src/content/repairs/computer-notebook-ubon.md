## ตรวจอาการก่อนเปลี่ยนอะไหล่

คอมเปิดไม่ติด ไม่ขึ้นภาพ หรือใช้งานช้า อาจมีต้นเหตุได้หลายส่วน การสรุปจากอาการเดียวอาจทำให้เปลี่ยนอะไหล่เกินความจำเป็น ร้านอำพล เทรดดิ้งจึงใช้ข้อมูลสเปก ประวัติการใช้งาน และการตรวจเครื่องจริงประกอบกันก่อนแจ้งแนวทาง

ตัวอย่างเช่น คอมไม่ขึ้นภาพอาจเกี่ยวกับจอ สายสัญญาณ RAM การ์ดจอ แหล่งจ่ายไฟ หรือเมนบอร์ด ส่วนโน้ตบุ๊กที่ชาร์จไม่เข้าอาจต้องตรวจทั้งอะแดปเตอร์ ช่องชาร์จ แบตเตอรี่ และวงจรไฟ ค่าใช้จ่ายจึงควรยืนยันหลังแยกจุดเสียได้แล้ว

## ซ่อมคอมพิวเตอร์ตั้งโต๊ะและคอมประกอบ

สำหรับคอมตั้งโต๊ะ ควรแจ้งสเปกหลักที่ทราบ เช่น CPU เมนบอร์ด RAM การ์ดจอ ชุดจ่ายไฟ และอุปกรณ์จัดเก็บข้อมูล พร้อมอธิบายว่าเครื่องมีไฟ พัดลมหมุน มีเสียงเตือน หรือดับหลังเปิดนานเท่าใด หากเพิ่งถอดประกอบ อัปเกรด หรือย้ายเครื่อง ควรแจ้งด้วย เพราะช่วยจำกัดจุดตรวจได้เร็วขึ้น

อาการเครื่องร้อนหรือดับเองควรตรวจฝุ่น การไหลเวียนอากาศ พัดลม ชุดระบายความร้อน และอุณหภูมิขณะทำงาน ไม่ควรสรุปว่าเป็นเพียงซิลิโคนแห้งโดยไม่ตรวจค่าจริง ส่วนอาการเกมเด้งหรือจอฟ้าอาจเกี่ยวข้องทั้งไดรเวอร์ ความเสถียรของ RAM อุณหภูมิ หรืออุปกรณ์จ่ายไฟ

## ซ่อมโน้ตบุ๊กและโน๊ตบุ๊คเกมมิ่ง

โน้ตบุ๊กมีชิ้นส่วนที่ออกแบบเฉพาะรุ่น การแจ้งรหัสรุ่นเต็มมีความสำคัญกว่าชื่อซีรีส์เพียงอย่างเดียว โดยดูได้จากสติกเกอร์ใต้เครื่อง กล่อง หรือหน้า System Information หากอาการเกี่ยวข้องกับไฟ ให้เตรียมอะแดปเตอร์ที่ใช้อยู่มาด้วย

งานที่พบได้มีทั้งจอ คีย์บอร์ด ทัชแพด บานพับ แบตเตอรี่ ช่องชาร์จ ระบบระบายความร้อน และระบบปฏิบัติการ แต่ละอาการต้องตรวจว่าปัญหาอยู่ที่ชิ้นส่วน สายเชื่อมต่อ หรือวงจรอื่นก่อนตัดสินใจเปลี่ยน

## เครื่องช้า อัปเกรด หรือแก้ระบบ Windows

ก่อนเพิ่ม RAM หรือเปลี่ยน SSD ควรดูว่างานที่ใช้ต้องการทรัพยากรแบบใด ตรวจสุขภาพอุปกรณ์เดิม พื้นที่ว่าง โปรแกรมที่ทำงานเบื้องหลัง และอุณหภูมิ หากอุปกรณ์จัดเก็บข้อมูลเริ่มผิดปกติ สิ่งสำคัญอันดับแรกอาจเป็นการลดการใช้งานและสำรองข้อมูล ไม่ใช่ทดสอบซ้ำเป็นเวลานาน

สำหรับปัญหา Windows บูตไม่ได้ อัปเดตแล้วมีข้อผิดพลาด โปรแกรมทำงานผิดปกติ หรือสงสัยมัลแวร์ ควรแจ้งว่าต้องเก็บไฟล์ใดไว้เป็นพิเศษก่อนเริ่มแก้ระบบ การลงระบบใหม่ไม่ใช่คำตอบสำหรับทุกอาการ และควรทำเมื่อทราบผลกระทบต่อโปรแกรม ลิขสิทธิ์ และข้อมูลแล้ว

## ขั้นตอนการนำเครื่องมาตรวจ

1. ส่งยี่ห้อ รุ่น สเปก และอาการทาง LINE หรือโทรสอบถาม
2. เตรียมอะแดปเตอร์ สายไฟ หรืออุปกรณ์ที่เกี่ยวข้องกับอาการ
3. สำรองข้อมูลสำคัญหากเครื่องยังทำงานได้
4. ร้านตรวจจุดที่เกี่ยวข้องและแจ้งแนวทาง ค่าใช้จ่าย และเวลาโดยประมาณ
5. ลูกค้าอนุมัติก่อนดำเนินงานที่มีค่าใช้จ่าย
6. ทดสอบอาการหลักและแจ้งเงื่อนไขของงานเมื่อส่งคืน

อย่าส่งรหัสผ่านหรือข้อมูลลับทางแชท หากงานต้องเข้าสู่ระบบเพื่อทดสอบ ให้ตกลงวิธีปลดล็อกกับร้านโดยตรง และออกจากระบบบัญชีที่ไม่เกี่ยวข้องเมื่อทำได้
