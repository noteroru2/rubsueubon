## ตัวอย่างเคสประเมินราคาคอมสำนักงานหลายเครื่องในเมืองอุบล

บริษัท ร้านค้า หรือสำนักงานในเมืองอุบลที่ปรับปรุงอุปกรณ์ IT มักมีคอมพิวเตอร์หลายเครื่องต้องการประเมินพร้อมกัน ตัวอย่างนี้เป็นแนวทางการเตรียมข้อมูลสำหรับคอมสำนักงานยกชุด ไม่ใช่ผลงานรับซื้อจริง การประเมินแบบหลายเครื่องต้องดูทั้งสเปกรายเครื่องและภาพรวมของล็อต เพื่อให้ตกลงเงื่อนไขได้ชัดก่อนนัดดูของจริง

## สินค้าที่นำมาประเมิน

- Desktop PC หรือ All-in-One หลายเครื่อง
- จอมอนิเตอร์ เมาส์ คีย์บอร์ด และสายไฟที่มีอยู่
- สเปกสำนักงาน เช่น Core i3/i5, RAM 8GB ขึ้นไป, SSD หรือ HDD
- อุปกรณ์ใช้งานในบริษัท ร้านค้า หรือหน่วยงาน
- พื้นที่เมืองอุบลราชธานี

## สภาพเบื้องต้น

ควรแยกจำนวนเครื่องที่เปิดติด ใช้งานได้ เครื่องมีอาการ และเครื่องเสียชัดเจน เช่น เปิดไม่ติด จอไม่ขึ้น พัดลมดัง หรือฮาร์ดดิสก์มีเสียงผิดปกติ หากมีจอมอนิเตอร์ให้ระบุขนาดและอาการด้วย เพราะจอที่มีเส้น จุดดำ หรือขาตั้งเสียจะประเมินต่างจากจอปกติ

## ข้อมูลที่ควรส่งให้ร้าน

ส่งตารางหรือข้อความสรุปจำนวนเครื่อง รุ่น CPU, RAM, Storage และจำนวนจอ ถ่ายรูปตัวอย่างเครื่องแต่ละกลุ่ม รูปหน้า System Properties หรือ Task Manager ถ้าเปิดได้ และรูปสภาพห้องเก็บของหรือจุดที่เครื่องวางอยู่เพื่อประเมินการขนย้ายเบื้องต้น ไม่ควรส่งไฟล์เอกสารบริษัทหรือข้อมูลลูกค้าประกอบการประเมิน

## ปัจจัยที่มีผลต่อราคา

จำนวนเครื่อง สเปกเฉลี่ย ความสม่ำเสมอของรุ่น สัดส่วนเครื่องที่เปิดติด ชนิด Storage สภาพจอ และความพร้อมของอุปกรณ์เสริมมีผลต่อราคาล็อต หากเป็นทรัพย์สินองค์กรควรมีผู้มีอำนาจอนุมัติการขาย และควรจัดการข้อมูลภายในให้เรียบร้อยก่อนส่งมอบ

## วิธีเตรียมเครื่องก่อนขาย

สำรองข้อมูลที่จำเป็น ลบข้อมูลหรือถอด Storage ตามนโยบายองค์กร ตรวจสอบบัญชีผู้ใช้ในเครื่อง จัดชุดสายไฟและอุปกรณ์เสริมให้ตรงกับจำนวนเครื่อง และเตรียมรายชื่อผู้ประสานงานที่ได้รับอนุมัติสำหรับการนัดตรวจสภาพ

## คำถามที่พบบ่อย

**ต้องส่งสเปกทุกเครื่องไหม?**  
ถ้าทำได้จะช่วยให้ประเมินใกล้เคียงขึ้น อย่างน้อยควรแยกกลุ่มเครื่องตามสเปกหลัก

**เครื่องที่ไม่มีฮาร์ดดิสก์ยังประเมินได้ไหม?**  
ประเมินได้ แต่ต้องแจ้งว่าถอด Storage แล้ว เพราะมีผลต่อราคาชุด

**ข้อมูลบริษัทต้องลบก่อนขายไหม?**  
ควรสำรองและลบข้อมูลตามนโยบายองค์กรก่อนส่งมอบทุกครั้ง
