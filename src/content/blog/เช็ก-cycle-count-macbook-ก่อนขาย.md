Cycle Count และ Battery Condition เป็นข้อมูลสำคัญเวลาประเมิน MacBook มือสอง เพราะช่วยบอกภาพรวมการใช้งานแบตเตอรี่และความพร้อมของเครื่องก่อนขาย บทความนี้สรุปวิธีเช็กข้อมูลด้วยตัวเองแบบปลอดภัย ไม่ต้องติดตั้งเครื่องมือแปลก ๆ และไม่ต้องส่งรหัสผ่านหรือข้อมูลส่วนตัวให้ใคร

## Cycle Count คืออะไร

Cycle Count คือจำนวนรอบการชาร์จสะสมของแบตเตอรี่ MacBook ไม่ได้เท่ากับจำนวนครั้งที่เสียบสายชาร์จตรง ๆ แต่เป็นการนับจากการใช้งานแบตเตอรี่รวมกันครบหนึ่งรอบ เช่น ใช้ไป 50% แล้วชาร์จกลับ จากนั้นใช้ไปอีก 50% จึงนับรวมเป็นหนึ่ง cycle โดยประมาณ

จำนวนรอบชาร์จที่สูงขึ้นไม่ได้แปลว่าเครื่องขายไม่ได้ แต่เป็นหนึ่งในปัจจัยที่ร้านใช้ประกอบกับสภาพจอ บอดี้ รุ่นชิป RAM, SSD และอุปกรณ์ที่มี

## วิธีเช็ก Cycle Count บน macOS

1. คลิกเมนู Apple มุมซ้ายบน
2. เลือก About This Mac
3. กด More Info หรือ System Report ตามเวอร์ชัน macOS
4. เข้าเมนู Power
5. ดูหัวข้อ Cycle Count และ Condition

ถ้าเมนูในเครื่องของคุณต่างจากนี้ อาจเป็นเพราะ macOS คนละเวอร์ชัน ให้ถ่ายรูปหน้า About This Mac ส่งมาพร้อมกัน ร้านจะช่วยดูข้อมูลที่จำเป็นสำหรับประเมินเบื้องต้นได้

## Battery Condition ดูอย่างไร

Battery Condition มักแสดงเป็นสถานะ เช่น Normal หรือ Service Recommended คำว่า Service Recommended ไม่ได้แปลว่าเครื่องไม่มีมูลค่า แต่แปลว่าควรประเมินเผื่อสภาพแบตเตอรี่และค่าใช้งานในอนาคต ส่วนเครื่องที่แบตเตอรี่บวม เครื่องดับเอง หรือชาร์จไม่เข้า ควรแจ้งอาการให้ชัดตั้งแต่แรก

## ส่งรูปอะไรให้ประเมินง่ายขึ้น

- รูปหน้า About This Mac ที่เห็นรุ่น ชิป RAM และปีเครื่อง
- รูปหน้า Power ที่เห็น Cycle Count และ Battery Condition
- รูปจอเปิดใช้งานพื้นหลังสว่าง
- รูปฝาบน ฝาล่าง ขอบเครื่อง และมุมที่มีรอย
- รูปอะแดปเตอร์ สาย MagSafe หรือ USB-C
- แจ้งว่ามีกล่อง ใบเสร็จ หรือประกันเหลือหรือไม่

## สิ่งที่ไม่ควรลืมก่อนขาย

ก่อนส่งมอบ MacBook ควรสำรองไฟล์ ออกจาก Apple ID ปิด Find My Mac และลบข้อมูลส่วนตัวตามขั้นตอนของ macOS หากเป็นเครื่องบริษัทหรือเครื่องที่ผูกบัญชีองค์กร ควรให้ผู้ดูแลระบบปลดบัญชีและยืนยันสิทธิ์การขายก่อน

## FAQ

**Cycle Count สูงยังขายได้ไหม?**  
ยังส่งประเมินได้ ราคาขึ้นอยู่กับรุ่น สภาพเครื่อง แบตเตอรี่ อุปกรณ์ และราคาตลาด

**ต้องถ่ายเลข Serial ส่งไหม?**  
ไม่จำเป็นในขั้นแรก หากถ่าย ควรส่งเท่าที่สบายใจและปิดข้อมูลส่วนตัวอื่น ๆ ได้

**MacBook ที่ติด Apple ID ขายได้ไหม?**  
ต้องออกจาก Apple ID และปิด Find My Mac โดยเจ้าของบัญชีก่อนส่งมอบ

## สรุป

การเช็ก Cycle Count ช่วยให้ร้านประเมิน MacBook ได้ง่ายขึ้น แต่ไม่ใช่ปัจจัยเดียวที่ใช้ตัดสินราคา ควรส่งรูปสเปก สภาพเครื่อง แบตเตอรี่ และอุปกรณ์พร้อมกัน เพื่อประเมินเบื้องต้นก่อนนัดตรวจเครื่องจริง
