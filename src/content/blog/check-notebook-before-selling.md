ก่อนขายโน๊ตบุ๊คหรือโน้ตบุ๊กมือสอง สิ่งที่ควรรู้ไม่ใช่แค่ยี่ห้อและสภาพภายนอก แต่รวมถึง CPU, RAM, SSD, รุ่นย่อย และอาการใช้งานจริง ข้อมูลเหล่านี้ช่วยให้ร้านประเมินเบื้องต้นได้ง่ายขึ้น และช่วยให้ผู้ขายตัดสินใจได้ว่าควรนัดตรวจเครื่องหรือไม่

หากต้องการดูบริการหลัก สามารถอ่านที่ [รับซื้อโน้ตบุ๊ก อุบล](/บริการ/รับซื้อโน้ตบุ๊ก-อุบล/), [รับซื้อคอมพิวเตอร์ อุบล](/บริการ/รับซื้อคอมพิวเตอร์-อุบล/) และ [รับซื้อโน้ตบุ๊กยกล็อต อุบล](/บริการ/รับซื้อโน้ตบุ๊กยกล็อต-อุบล/)

## CPU ต้องดูอะไร

CPU คือหัวใจของเครื่อง ควรดูชื่อเต็ม เช่น Intel Core i5-1135G7, Core i7-12700H, AMD Ryzen 5 5500U หรือ Ryzen 7 6800H ตัวเลขรุ่นและ generation มีผลต่อความต้องการในตลาดมากกว่าแค่คำว่า i5 หรือ i7 เพราะ i5 รุ่นใหม่บางตัวอาจน่าสนใจกว่า i7 รุ่นเก่าหลายปี

## RAM และ SSD สำคัญอย่างไร

RAM 8GB ยังเพียงพอสำหรับงานเอกสารทั่วไป ส่วน 16GB เหมาะกับงานหลายหน้าต่าง งานเรียน หรือโปรแกรมที่ใช้ทรัพยากรเยอะ Storage แบบ SSD มักประเมินได้ง่ายกว่า HDD เพราะเครื่องตอบสนองไวกว่า ควรแจ้งทั้งความจุและชนิดไดรฟ์ เช่น SSD 256GB, SSD 512GB หรือ HDD 1TB

## รุ่นเครื่องและสภาพภายนอก

ชื่อรุ่นบนตัวเครื่องหรือใต้เครื่องช่วยให้ตรวจสเปกได้เร็วขึ้น ควรถ่ายรูปสติกเกอร์รุ่น เลข Model เท่าที่สะดวก และรูปสภาพจอ คีย์บอร์ด บานพับ พอร์ต และอะแดปเตอร์ หากมีรอยตก จอแตก คีย์บอร์ดเสีย แบตบวม หรือเครื่องเปิดไม่ติด ควรแจ้งตั้งแต่แรก

## วิธีดูสเปกบน Windows

1. กด Windows + R แล้วพิมพ์ `dxdiag` เพื่อดู CPU และ RAM
2. เปิด Task Manager > Performance เพื่อดู CPU, Memory และ Disk
3. เปิด Settings > System > About เพื่อดูชื่อเครื่องและรายละเอียดพื้นฐาน
4. ถ่ายรูปหน้าจอเหล่านี้ส่งให้ร้านพร้อมรูปตัวเครื่อง

## ส่งรูปอะไรให้ประเมินง่ายขึ้น

- รูปหน้า System > About หรือ Task Manager
- รูปตัวเครื่องด้านหน้า ด้านหลัง และใต้เครื่อง
- รูปจอขณะเปิดใช้งาน
- รูปคีย์บอร์ด บานพับ และพอร์ต
- รูปอะแดปเตอร์และกล่องถ้ามี
- แจ้งอาการ เช่น แบตเสื่อม เครื่องร้อน พัดลมดัง หรือเปิดไม่ติด

## สิ่งที่ไม่ควรลืมก่อนขาย

สำรองไฟล์ ลบข้อมูลส่วนตัว ออกจากบัญชี Microsoft, Google, LINE PC หรือแอปทำงานอื่น ๆ และถอดอุปกรณ์เก็บข้อมูลส่วนตัว หากเป็นเครื่องบริษัทควรได้รับอนุมัติจากผู้มีอำนาจก่อนขาย

## FAQ

**ไม่มีความรู้เรื่องสเปก ส่งรูปให้ร้านดูได้ไหม?**  
ได้ ถ่ายหน้า About และรูปตัวเครื่องส่งมาก่อน ร้านจะช่วยดูข้อมูลที่จำเป็น

**โน้ตบุ๊กเปิดไม่ติดยังประเมินได้ไหม?**  
ประเมินได้บางกรณี แต่ต้องแจ้งอาการและรุ่นให้ชัด

**เครื่องไม่มี SSD มีแต่ HDD ยังขายได้ไหม?**  
ส่งประเมินได้ ราคาจะดูตามรุ่น สภาพ และความต้องการของตลาด

## สรุป

การเช็ก CPU, RAM, SSD และรุ่นเครื่องก่อนขายช่วยให้ประเมินราคาเบื้องต้นได้ง่ายขึ้น หากมีโน้ตบุ๊กในอุบล ส่งรูปสเปก สภาพ และอุปกรณ์ที่มีทาง LINE เพื่อประกอบการตัดสินใจก่อนได้
