# Batch 17: GSC Data Deep Audit & Production QA Plan

## Executive Summary
หลังจากโครงการพัฒนาใน Batch 1–16 เสร็จสิ้น เว็บไซต์ รับซื้ออุบล.com มีจำนวนหน้าคุณภาพสะสมรวมประมาณ 228 หน้า (227 URLs ใน sitemap) และติดตั้งระบบ Mobile CTA พร้อมระบบวิเคราะห์เหตุการณ์ (Event Tracking) เป็นที่เรียบร้อยแล้ว 

ภารกิจใน **Batch 17** คือการหยุดขยายจำนวนหน้าเว็บใหม่ เพื่อเข้าสู่กระบวนการตรวจสอบเชิงลึกและการวิเคราะห์ข้อมูลจริงจาก Google Search Console (GSC) เพื่อนำข้อมูลทราฟฟิก, Impressions และการจัดทำดัชนี (Indexing) จริงของ Google มาปรับปรุงสิทธิประโยชน์การสำรวจและการดันพลังลิงก์ภายในอย่างมีประสิทธิภาพสูงสุด โดยหากยังไม่สามารถเข้าถึง GSC ได้ จะดำเนินแผนทางเลือก (Fallback Plan) ด้วยการตรวจวัดคุณภาพ 50 ลิงก์บนระบบจริง (Live Production QA) เพื่อประกันเสถียรภาพความเร็ว ประสิทธิภาพ และความสอดคล้องตามกฎระเบียบ

- **จำนวนหน้าเว็บทั้งหมด**: ~228 หน้า
- **จำนวน URL ใน Sitemap**: ~227 URLs
- **หน้าเป้าหมายหลัก**: หมวดหมู่บริการ (Services) 129 หน้า, พื้นที่ (Areas) 27 หน้า และบทความรวมถึงตัวอย่างเคส
- **หน้า Landmark คีย์เวิร์ดสำคัญ**: `/พื้นที่/ubon-university/` (ต้องมี HTTP 200 OK และห้ามหลุด 404)
- **ระบบติดตามการแปลงเป้าหมาย**: เพิ่ม Event tracking ของปุ่ม LINE / Tel เรียบร้อยแล้ว (Batch 13–14)
- **ข้อมูลหัวกระดาษหลัก**: ได้ทำการปรับแต่ง Title/Meta และกระตุ้นลิงก์เชื่อมโยงแบบปลอดภัยใน Batch 16 เรียบร้อยแล้ว

## Required Inputs
สำหรับการวิเคราะห์เชิงรุก ต้องดาวน์โหลดรายงานดิบ (Raw Export) จาก GSC ดังนี้:
1. **Search results > Pages > Last 3 months** (ไฟล์ Clicks & Impressions รายหน้า)
2. **Search results > Queries > Last 3 months** (ไฟล์ Keyword Performance รายคำค้นหา)
3. **Page indexing export** (สถิติหน้าได้รับการจัดทำดัชนีและสาเหตุของหน้าที่ถูกปฏิเสธ)
4. **Sitemap status** (รายงานสถานะการส่งแผนผังเว็บสม่ำเสมอของบ็อท)
5. **Not indexed URLs export** (รายชื่อ URL ที่ค้างอยู่ในคิวสำรวจเพื่อแก้ปัญหาเชิงรุก)

## Analysis Framework
จะจัดจำแนกกลุ่ม URL ทั้งหมดหลังจากได้รับข้อมูลจริงออกเป็น 6 กลุ่มหลัก:
- **KEEP**: หน้าที่ติดอันดับยอดเยี่ยม ทราฟฟิกสูง ให้รักษารูปแบบและประสิทธิภาพความเร็วต่อไป
- **IMPROVE**: หน้าที่มียอดแสดงผล (Impressions) ดี แต่อัตราการคลิกเข้าชม (CTR) ต่ำ ➡️ ดำเนินการปรับปรุง Title และ Meta เพื่อดึงดูดคลิก
- **INTERNAL LINK BOOST**: หน้าที่มีคุณภาพ มีเนื้อหาเชิงลึกดี แต่ทราฟฟิกยังต่ำและขาดแคลนลิงก์ภายใน ➡️ ทำการยกระดับการเชื่อมโยงจากหน้า Hub หลัก
- **MERGE REVIEW**: หน้าที่มีเจตนาในการค้นหาตรงกันเกือบ 100% จนแย่งอันดับกันเอง ➡️ วางแผนยุบรวมเนื้อหาและส่งลิงก์ถาวร 301
- **NOINDEX CANDIDATE**: หน้าข้อมูลทั่วไปหรือหน้าประวัติขยะที่ไม่จำเป็นต้องดึง Crawl Budget ➡️ ติดตั้ง noindex 
- **WATCH**: หน้าสร้างใหม่ที่กำลังเริ่มเติบโต ➡️ เฝ้าสังเกต Impressions อย่างใกล้ชิด

## Cannibalization Groups to Review
กลุ่มหัวข้อบริการเชิงรุกที่ต้องตรวจสอบการแสดงผลซ้ำซ้อนในอันดับค้นหาของ Google:
- **iPad Cluster**: หน้า iPad หลัก ➡️ หน้า ม.อุบล ➡️ หน้าเคสตัวอย่าง iPad Pro
- **MacBook Cluster**: หน้า MacBook หลัก ➡️ หน้าชิป M-series ➡️ หน้าเคสตัวอย่าง MacBook Air
- **iPhone Model Cluster**: หน้าหลัก iPhone ➡️ หน้ารุ่นสินค้าแต่ละเจเนอเรชั่น
- **Android Brand Cluster**: หน้า Samsung ➡️ หน้ารุ่น Ultra ➡️ หน้ารุ่นอื่นๆ
- **B2B Cluster**: หน้าคอมบริษัท ➡️ หน้าคอมสำนักงาน ➡️ หน้าคอมยกล็อต ➡️ หน้าคอมร้านเกม
- **Camera / Creator Gear**: หน้ากล้องหลัก ➡️ แบรนด์กล้อง ➡️ เลนส์กล้อง
- **Game Console / Handheld**: หน้าเครื่องเกมรวม ➡️ หน้า Nintendo Switch ➡️ หน้า PS5 ➡️ หน้าเครื่องเกมพกพา
- **PC Parts / Gaming Hardware**: หน้ารวมชิ้นส่วนคอมพิวเตอร์ ➡️ หน้าการ์ดจอ RTX ➡️ หน้าซีพียู

## Fallback Plan if No GSC Data
**Batch 17A: Live Production QA 50 URLs**
กรณีไม่มีไฟล์รายงานดิบจาก GSC ให้เปลี่ยนมาตรวจสอบคุณภาพและประสิทธิภาพหน้าเว็บจริงจำนวน 50 หน้า (คัดเลือกจาก 10 service hub/main pages, 10 model/brand pages, 10 area pages, 10 blog/support articles, 10 case/example pages) โดยจะตรวจวัดคุณลักษณะดังนี้:
- **HTTP status**: ตรวจสอบสถานะการเชื่อมต่อ ต้องเป็น 200 OK
- **Canonical**: ตรวจเช็คแท็ก canonical ต้องชี้หาตัวเองอย่างถูกต้อง ปราศจาก redirect loop
- **Title / Meta / H1**: ตรวจสอบการซ้ำซ้อนและการจัดสเปซโครงสร้าง
- **CTA / Mobile UX**: ตรวจสอบความถูกต้องของปุ่มติดมุมล่าง (Mobile Sticky CTA) และฟังก์ชั่นการส่งประเมินราคา
- **Claim Risk**: ตรวจจับคำเคลมต้องห้ามรอบสุดท้าย
- **Horizontal Overflow / Mobile CSS**: ตรวจสอบความลื่นไหล CSS บนขนาดหน้าจอมือถือ ต้องไม่มีสกรอลล์แนวนอน

## Batch 18 Candidates
แผนปฏิบัติการล่วงหน้าหลังจากสิ้นสุดการวิเคราะห์ใน Batch 17:
1. **Batch 18A**: ดำเนินการแก้ไข Title & Meta ตามข้อมูลคำค้นจริงจาก Google Search Console (เน้นดึง CTR)
2. **Batch 18B**: ดำเนินการแทรกลิงก์ส่งพลัง PageRank จากหน้าที่มี Authority สูงไปยังหน้าเฉพาะทางที่มีอันดับใกล้เคียงหน้าแรก
3. **Batch 18C**: จัดการควบรวมหน้า (Merge) และจัดทำระบบ 301 Redirect สำหรับหน้าบริการ/พื้นที่ที่ทับซ้อนกันโดยสมบูรณ์

---

## Rules
- ห้ามเพิ่มหรือสร้างหน้าใหม่เข้าสู่ระบบ
- ห้ามใส่ noindex, merge หรือ redirect หน้าใดๆ จนกว่าข้อมูล GSC จะชัดเจน
- ห้ามใช้คำกล่าวอ้างโฆษณาเกินจริง (Claim Risk)
- ต้องผ่านการรันคอมไพล์บิลด์และ QA ตรวจโครงสร้างลิงก์ก่อนส่งงานเสมอ
